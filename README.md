    <h1>void</h1>
    <h3>an abandoned macOS menu bar addon that spins up local services quickly</h3>
</div>

<br><br>

void is a menu bar addition for macOS. it allows you to quickly spin up preconfigured local services from your machine. i decided to abandon it after:

1. it began to seem like i was fighting OS permission limits
2. i didn't feel comfortable enough with running background services on my primary machine in such a fashion

i found that i'd honestly just run the services manually. doesn't that make things simple?
